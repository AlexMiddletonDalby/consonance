# Consonance

Consonance is a rust crate containing types for working with musical concepts such as notes, chords, intervals, scales, and keys, as well as some utilities for common operations like transposition and re-harmonization.
The aim is for this crate to eventually contain everything you might need for building an app which deals with musical theory.

## Planned features:
- [x] Simple idiomatic Rust types for the building blocks of musical harmony: Notes, Chords, Keys and Scales
- [x] Search for keys by their basic diatonic chords
- [ ] Automatic recognition and naming of complex chords by their notes/intervals
- [ ] MIDI support, to allow notes and chords to be converted to MIDI messages
- [ ] Types for rhythmic concepts like Beats, Bars, Time Signatures etc.

## ⚠️ Current State
_This project is currently in quite an early stage, and is mostly being used as a common library for a couple of apps I'm working on. I do want to eventually make this a library that would be useful for others to use, but right now things could change and be reworked at any time. You have been warned._
